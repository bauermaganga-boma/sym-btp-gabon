# SY'M BTP GABON — Site vitrine

Site vitrine de **SY'M BTP GABON**, entreprise gabonaise du bâtiment et des travaux publics basée à Akanda (Libreville).

Contenu et visuels issus de la *Présentation institutionnelle et technique* de l'entreprise (`SYM_BTP_GABON_Presentation_institutionnelle.pdf`).

## Structure

```
index.html            Page unique (profil, implantation, vision, expertises, démarche,
                      réalisations, moyens, références, siège, contact)
assets/css/style.css  Styles (palette brun/or issue du logo, responsive)
assets/js/main.js     Menu mobile, animations, filtres de galerie, visionneuse, formulaire
assets/img/           Logo et photos extraits de la présentation
```

Site 100 % statique, sans dépendance ni étape de build. Le formulaire de contact ouvre la messagerie de l'internaute avec une demande pré-remplie à destination de `symbtp@gmail.com`.

## Aperçu local

Ouvrir `index.html` dans un navigateur, ou servir le dossier avec n'importe quel serveur statique.

## Mise en ligne

Compatible GitHub Pages : *Settings → Pages → Deploy from a branch → `main` / root*.
